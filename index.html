Konfigurasi Cloudinary

Pengaturan ini digunakan untuk mengunggah foto siswa, guru, profil pengguna, serta gambar materi/tugas.

Penggunaan di GitHub: simpan file config.json hasil unduhan di folder utama repository, sejajar dengan index.html. File HTML lain seperti tugas.html dapat membaca file yang sama menggunakan fetch('./config.json').
Upload preset harus benar-benar bertipe Unsigned di Cloudinary. Nama preset dapat terlihat oleh pengunjung website; batasi format hanya gambar (jpg, jpeg, png, webp) dan atur batas ukuran/pengamanan di pengaturan preset. Jangan pernah memasukkan API Secret ke HTML atau config.json.
